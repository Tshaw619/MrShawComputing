Inline Text Formatting & Styling Tags

Inline tags style specific portions of text within a line without starting a new block. Click on any tag in the table to test its properties and see it in action!

Tag Name / Description Live Example Render
<b> Bold text (visual weight without extra importance) This is bold text.
<strong> Strong importance (rendered bold by default, indicates high importance) This is very important text.
<i> Italic text (alternate voice or technical term in italics) The term software is crucial.
<em> Emphasised text (stress emphasis, rendered in italics) Always check your work carefully.
<u> Underlined text (unarticulated annotation or underline styling) Please note this highlighted section.
<mark> Highlighted/Marked text (yellow background highlight for reference) Remember to save your progress often.
<code> Computer code snippet (monospace font for programming code) Use the print() function in Python.
<span> Generic inline container (used with CSS for styling custom spans) This has a custom coloured word.
<sub> Subscript text (lowered baseline text, e.g. chemical formulas) Water chemical formula is H2O.
<sup> Superscript text (raised baseline text, e.g. mathematical powers) Area in square meters: m2.
<small> Smaller text (fine print or side comments) Terms apply (see small print).
<del> Deleted text (strikethrough text indicating deletion) Price: £19.99 £14.99
<ins> Inserted text (underlined text indicating an addition) Updated status: Active
<q> Short quotation (inline quotation enclosed in quotation marks) She said Code is poetry.
<kbd> Keyboard input (monospace styled representation of keyboard keys) Press Ctrl + C to copy.
