YEAR 8 COMPUTING

HTML Match & Pair

Can you match HTML tags to their jobs, then spot mistakes like a web developer?

Learning goal

Identify common HTML tags and explain how they are used to build a webpage.

Instructions: Choose the correct meaning for each tag. Select Check my matches when you are ready. You can try again!

ACTIVITY 1 · MATCH & PAIR

Which tag does what?

Match each tag to its purpose using the dropdown menus.

Remember: an opening tag often has a matching closing tag, for example <p> and </p>.

ACTIVITY 2 · PREDICT

What will the browser show?

Look at the code, then click one answer for each question. No writing needed!

<h1>My Favourite Food</h1>
<p>I enjoy making pizza.</p>
<img src="pizza.jpg" alt="A pizza">

1. Which text will be displayed as the main heading?

2. What might happen if pizza.jpg cannot be found?

Tip: Heading tags show headings. The alt attribute provides alternative text for an image.
