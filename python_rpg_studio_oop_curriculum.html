Chapter 02 • Object Interaction & State Guardrails

Combat & Object Interaction

Objects become truly powerful when they interact with other objects. In this step, you will pass an entire enemy Character object into an attack(self, target) method, and introduce max_hp so healing never overflows!

hero.attack(goblin)

Inside attack(self, target), self is the attacker and target is the victim object—so you can call target.take_damage(self.attack_power)!

self.max_hp

Tracking maximum HP allows heal(amount) to cap health cleanly without over-healing past full strength.

class Warrior(Character):
    def __init__(self, name):
        super().__init__(name, hp=130, attack_power=16)
        self.armor = 4

    def take_damage(self, amount):
        reduced = max(0, amount - self.armor)
        print(f"{self.name}'s armor blocks {self.armor} damage!")
        super().take_damage(reduced)

    def special_move(self, target):
        dmg = int(self.attack_power * 1.5)
        print(f"{self.name} uses SHIELD BASH on {target.name} for {dmg} damage!")
        target.take_damage(dmg)


class Mage(Character):
    def __init__(self, name):
        super().__init__(name, hp=85, attack_power=12)
        self.mana = 60

    def special_move(self, target):
        if self.mana >= 20:
            self.mana -= 20
            print(f"{self.name} casts FIREBALL for 32 damage! (Mana left: {self.mana})")
            target.take_damage(32)
        else:
            print("Not enough mana! Basic attack used instead.")
            self.attack(target)

            Quick Reference
            
Python OOP Cheat Sheet

            
Keep this vocabulary handy while coding your RPG project.

          

          

            
            
          

        


        

          

            
Class vs. Object (Instance)

            
A Class is the blueprint (e.g., Character). An Object is a real item built from that blueprint in memory (e.g., hero = Character("Aria", 100, 15)).

            class Character: ...
          


          

            
__init__ & self

            
__init__ initializes an object's starting attributes. self refers to the specific object currently executing the method.

            def __init__(self, name): self.name = name
          


          

            
Inheritance & super()

            
Allows a child class to inherit attributes and methods from a parent class without duplicating code. super() calls the parent's version of a method.

            class Warrior(Character): ...
          


          

            
Polymorphism

            
Different subclasses can share the same method name (like .special_move()) while executing completely different behavior under the hood.

            player.special_move(boss)
